How to access

Open the collection page and use the download control in the Data Access table (TCIA Data Retriever or Aspera, whichever that row names). A public Creative Commons row does not need an application. Read the Citations & Data Usage Policy tab before use.

Limitations

Formerly limited-access. The collection page says that as of April 2026, after discussion with the PI, it is public under CC BY 4.0. DCE-MRI only, three time points, and not every patient completed all visits. Acknowledge NIH award U01 CA154602 as the page requests. Not the same files as Soft-tissue-Sarcoma.

Citation required?

Yes. Cite the collection DOI on the TCIA page and follow the TCIA Data Usage Policy. Also acknowledge U01 CA154602.
