How to access

Register at data.midrc.org (InCommon or ORCID, as the login page offers) and accept the data-use agreement. The current text is linked from https://www.midrc.org/midrc-data-use-agreement and from the portal. Download only after the agreement is accepted.

Limitations

The default academic agreement is personal, non-commercial research at a non-profit or government institution. It forbids redistributing the data, and it is not a Creative Commons license. A commercial agreement is a different document. Collections can include reports and clinical fields; do not treat every row as images alone. RICORD on TCIA is CC BY-NC and is not this portal.

Citation required?

Yes. Acknowledge MIDRC in presentations and papers, using the wording on https://www.midrc.org/midrc-acknowledgements

Related open-source tools

  • TorchXRayVision: Library of chest X-ray dataset loaders and pretrained classification, segmentation and autoencoder models
  • CheXagent: Foundation model for chest X-ray interpretation
  • MedRAX: Reasoning agent for chest X-rays that orchestrates multiple CXR models (ICML 2025)
  • Pillar-0 (finetune code + HF weights): Open 3D radiology foundation model; finetuning framework, weights on Hugging Face
  • TotalSegmentator: Segments more than 100 anatomical structures in CT and MR
  • pydicom: Read, modify and write DICOM files in Python
  • highdicom: High-level Python API on pydicom for reading images and writing AI results as DICOM Segmentation, Structured Report, parametric map and annotation objects
