How to access

Open the collection page and use the download control in the Data Access table (TCIA Data Retriever or Aspera, whichever that row names). A public Creative Commons row does not need an application. Read the Citations & Data Usage Policy tab before use.

Limitations

Glioblastoma cohort, not healthy controls. NIfTI volumes are registered to an atlas and do not align with the DICOM by design. Histopathology is NDPI, not radiology. Skull-stripped NIfTI is a different object from the DICOM.

Citation required?

Yes. Cite the collection DOI on the TCIA page and follow the TCIA Data Usage Policy.
