How to access

Create a PhysioNet account, complete CITI “Data or Specimens Only Research” training, and sign the Credentialed Health Data Use Agreement 1.5.0. Download the DICOM release (version 2.1.0), not only MIMIC-CXR-JPG, if you need DICOM.

Limitations

Credentialed research use only. No sharing, no re-identification, and code from papers that use the data should be shared back. Reports are included and were de-identified (PHI replaced with ___). Images had burned-in text removed. This is a hospital population, so “normal” means no acute finding was described, not a healthy-volunteer study. JPEG derivatives are a different PhysioNet project.

Citation required?

Yes. Johnson et al., MIMIC-CXR Database (version 2.1.0), PhysioNet. https://doi.org/10.13026/4jqj-jw95
