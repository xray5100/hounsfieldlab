How to access

Open the collection page and use the download control in the Data Access table (TCIA Data Retriever or Aspera, whichever that row names). A public Creative Commons row does not need an application. Read the Citations & Data Usage Policy tab before use. Download uses the Aspera plugin named on the page. Images are NIfTI, not DICOM.

Limitations

Organ-segmentation set, not a pediatric set (see Pediatric-CT-SEG for pediatric chest/abdomen/pelvis contours). Many volumes come from LiTS and contain liver lesions. A few volumes are left-right flipped. Training labels for lung and bone were partly automatic.

Citation required?

Yes. Cite the collection DOI on the TCIA page and follow the TCIA Data Usage Policy.

Related open-source tools

  • Pillar-0 (finetune code + HF weights): Open 3D radiology foundation model; finetuning framework, weights on Hugging Face
  • nnU-Net: Self-configuring segmentation framework
  • TorchIO: Medical image loading, preprocessing and augmentation for PyTorch
  • SimpleITK: Simplified interface to ITK for image I/O, filtering, segmentation and registration in Python, R, Java, C# and other languages
