How to access

Use the AWS Open Data page. The bucket s3://msd-for-monai can be listed and downloaded with the AWS CLI and --no-sign-request, so no AWS account is needed. MONAI also ships a loader for these tasks. Task descriptions are on medicaldecathlon.com.

Limitations

Built for a 2018 segmentation challenge, so each task targets one structure or lesion and the cohorts are small for some tasks (left atrium has 30 volumes). Test-set labels are withheld. The brain tumor task is drawn from BraTS 2016–2017 and the lung task from TCIA, so check overlap before combining with those sources. Share-alike applies if you redistribute adapted data.

Citation required?

Yes. Cite Simpson et al., A large annotated medical image dataset for the development and evaluation of segmentation algorithms (arXiv:1902.09063), and Antonelli et al., Nature Communications 2022.
