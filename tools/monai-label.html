MONAI Label

AI-assisted image labeling and active learning; integrates with 3D Slicer and OHIF

LICApache-2.0UPD2026-11-22STATUSMaintainedCOMMPermissive

Security: Versions up to 0.8.5 have a critical path-traversal flaw (CVE-2026-133968, CVSS 9.8) in the datastore and session upload endpoints that allows remote file writes and code execution; authentication is off by default, and it has been exploited in the wild. Upgrade to 0.8.6 or later (released Nov 21, 2026; requires Python 3.11+), don't expose the server to untrusted networks, enable authentication, and run it as an unprivileged user.

Related tools in Segmentation & frameworks

  • MONAI: PyTorch-based AI toolkit for healthcare imaging
  • nnU-Net: Self-configuring segmentation framework
  • TotalSegmentator: Segments more than 100 anatomical structures in CT and MR
  • TotalSpineSeg: Two-stage nnU-Net tool that segments and individually labels every vertebra and intervertebral disc plus the spinal cord and canal, using an odd/even vertebra scheme and landmark discs (C2-C3, C7-T1, T12-L1, L5-S) to avoid fused or split vertebrae; works on localizers and short-FOV scans; peer-reviewed in European Radiology (Nov 7, 2026)
  • CXAS: Chest X-ray anatomy segmentation (Mask2Former models: 187 frontal and 177 lateral classes) plus 132 named landmarks and landmark-based measurements such as cardiothoracic ratio, costophrenic angle, Cobb angle and the Haller index, in mm for DICOM input; cxas_idc writes one multi-segment DICOM SEG and a TID 1500 SR per radiograph; trained on PAXRay++ CT-projected radiographs
  • NV-Segment-CT: CT segmentation built from MONAI VISTA3D: 117 structures automatically, or 132 promptable by point or class. Research use only, not for clinical care. Needs a CUDA GPU; weights are about 872 MB
